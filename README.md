# TypeScript Projects

Small browser apps written in TypeScript (strict mode) with no frameworks or libraries. Each folder is a separate project with its own README and setup.

| Project | What it shows |
|---|---|
| [Tic-Tac-Toe AI](tic-tac-toe-ai) | Minimax algorithm with alpha-beta pruning |
| [Expense Tracker](expense-tracker) | Type modeling, canvas chart, CSV export |
| [Weather Dashboard](weather-dashboard) | Fetch API, debounced search, live forecasts |
| [Typing Speed Test](typing-speed-test) | Real-time UI, timers, scoring |

To run any project, open its folder and follow the README there.
